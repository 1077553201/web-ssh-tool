## ✨ 功能特性

- **可视化配置**：直观填写主机、用户、端口及密钥路径，自动拼接复杂命令。

- **隧道与代理**：一键生成动态代理 (`-D`)、本地映射 (`-L`) 和内网穿透 (`-R`) 参数。

- **高级参数支持**：支持压缩 (`-C`)、静默模式 (`-N -f`)、X11 转发等常用选项。

- **模拟终端体验**：内置基于 Xterm.js 的模拟终端，支持打字机效果演示。

- **响应式设计**：完美适配桌面端、平板和移动端操作。

- **彩蛋系统**：包含代码雨、爱心、烟花等视觉特效及隐藏命令。

---

## 🛠️ 技术栈

- **核心**：HTML5, JavaScript (ES6+)

- **样式**：Tailwind CSS (CDN)

- **组件**：Xterm.js (模拟终端), FontAwesome (图标)

- **动画**：HTML5 Canvas, CSS3 Animations

---

## 🚀 快速开始

本项目为单文件应用，无需安装任何依赖或构建过程。

1. 下载或克隆本项目。

2. 双击打开 `index.html` (原文件名 `SSH_Generator_Fixed.html`)。

3. 开始使用！
