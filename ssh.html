动态代理 (SOCKS5)

后台隧道管理

查找和关闭后台SSH隧道进程：

Windows (PowerShell)
# 查找进程：
Get-CimInstance Win32_Process -Filter "Name = 'ssh.exe'" | Select-Object ProcessId, CommandLine
# 关闭进程：
taskkill /F /PID <进程号>
Linux / macOS
# 查找进程：
ps aux | grep "ssh.*-f.*-N"
# 或者
pgrep -f "ssh.*-f.*-N"
# 关闭进程：
kill # 正常关闭
kill -9 # 强制关闭
重要提示：
• 必须在发起SSH的本地电脑关闭进程，而不是服务器
• -L端口开在本地，-R端口开在服务器
• 在服务器杀sshd进程可能导致僵尸进程
• 强制关闭(-9/-F)可能需要重新连接验证
